# Establish power evidence before changing load management

The team has Driver Station-confirmed brownouts with concurrent drive and mechanism loads, but lacks synchronized evidence identifying the limiting conditions. The first release records REV PDH, motor, mechanism, and robot-health data while retaining existing current limits and drive behavior; field trials will determine later changes rather than guessing a universal current budget. The initial candidate for a later trial is gentler drivetrain acceleration under combined load, preserving sufficient intake-extension torque.
